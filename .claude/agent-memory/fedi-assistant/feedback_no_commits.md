---
name: Pas de commits automatiques
description: Ne jamais créer de commits git sans demande explicite
type: feedback
---

Ne jamais exécuter `git commit` sans que l'utilisateur le demande explicitement.

**Why:** L'utilisateur veut garder le contrôle total sur l'historique git de son PFE.

**How to apply:** À chaque session, écrire les fichiers directement mais ne lancer aucune commande git commit/push.
